# Homepage video

Upload your licensed video as `home-hero.mp4` in this folder, then rebuild.
Use H.264 MP4, landscape 16:9, ideally 720p–1080p and under 8 MB, with no audio track.
The build activates the video only when the file exists. Until then, the hero
uses a forest-coloured background, not the previous mountain photo.
Playback is muted and inline, with a visible pause/play control. Reduced-motion
and data-saving visitors get manual playback. Do not embed important text in the
video; the homepage heading and links remain real accessible HTML.
