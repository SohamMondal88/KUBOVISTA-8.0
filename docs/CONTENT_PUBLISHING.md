# KuboVistas editorial publishing checklist

Use this checklist before publishing or materially updating a public guide. It is designed to keep the Journal useful to travelers and avoid thin, duplicated or artificially refreshed pages.

## Every guide must

- Answer a real travel-planning question for a clearly defined reader.
- Be written from scratch. Do not rewrite another site, supplier brochure or generated search result.
- Contain at least 300 useful words and four descriptive sections; add more only when the subject needs it.
- Separate durable advice from details that can change, such as permits, access, prices, transport and weather.
- Link changeable claims to the relevant government, tourism or official operator source.
- Show the actual publication date and the date of the last meaningful editorial review.
- Identify the KuboVistas Editorial Team and provide a correction route through `/company/contact`.
- Use a unique title, introduction, canonical URL and reader-focused description.
- Add useful internal links to relevant destinations, journeys or other guides without keyword stuffing.
- Use photographs only when KuboVistas owns them or has documented permission, with accurate alternative text.

## Review before changing `updated`

Read the full article, open every official source, verify the changeable details and revise the copy where needed. Do not change the review date only to make a page appear fresh. After a meaningful update, run `npm run check && npm run build`, inspect the generated Article JSON-LD and confirm the article's `<lastmod>` in `dist/sitemap.xml`.

## Suggested publishing rhythm

Publish when there is a genuinely useful topic rather than filling a calendar. A sustainable initial target is two carefully reviewed guides per month, plus prompt corrections when official rules change. Keep a private research note for sources, reviewer and material changes.

## AdSense readiness

Advertising must never be the primary purpose of a page. Keep ads visually distinct from editorial content, do not place ads on empty or unfinished routes, and do not encourage clicks. The root `ads.txt` record must remain exactly aligned with the publisher ID generated by `scripts/adsense-config.mjs`.
